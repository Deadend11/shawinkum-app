# شاوينكم — Android starter

هذا مشروع أولي بـ Kotlin وJetpack Compose، وليس تطبيقاً مكتملاً مثل TikTok.

## التشغيل
1. فك ضغط الملف.
2. افتح مجلد `ShawinkumAndroid` في Android Studio.
3. انتظر Gradle Sync.
4. شغّل التطبيق على جهاز Android أو المحاكي.

## الموجود حالياً
- واجهة رئيسية تجريبية للفيديوهات.
- تبويبات الرئيسية والبحث والنشر والإعجابات والحساب.
- اختيار فيديو من الجهاز عبر منتقي الملفات.
- صفحة حساب فيها مساحة غلاف تجريبية.

## غير المنفذ بعد
تسجيل الحسابات، رفع الفيديو إلى خادم، تشغيل فيديوهات من الإنترنت، قاعدة بيانات، المتابعة والتعليقات الحقيقية، الرسائل، الإشعارات والبث المباشر. هذه تحتاج backend وتخزيناً واستضافة وإعدادات أمان وخصوصية.
